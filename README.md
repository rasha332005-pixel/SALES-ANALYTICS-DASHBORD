# 📊 Sales Analytics Dashboard – Excel

## 📌 Project Overview

The **Sales Analytics Dashboard** is an interactive dashboard created entirely using **Microsoft Excel**.
The project analyzes sales data and presents key business insights through **KPIs, charts, tables, and interactive slicers**.

The dashboard helps users understand sales performance, product performance, customer trends, and regional sales.

## 🎯 Objectives

* Analyze overall sales performance
* Track important sales KPIs
* Identify top-performing products
* Analyze sales by region and category
* Understand customer purchasing trends
* Compare sales performance across different periods
* Create an interactive and easy-to-use dashboard

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Excel Formulas & Functions
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Cleaning
* Data Analysis
* Dashboard Design

## 📈 Key KPIs

The dashboard includes important metrics such as:

* 💰 **Total Sales**
* 📦 **Total Orders**
* 🛒 **Total Quantity**
* 📊 **Average Sales**
* 💵 **Profit / Margin**
* 🏆 **Top Product**

## 📊 Dashboard Features

* Interactive **Slicers**
* Sales performance analysis
* Product-wise sales analysis
* Region-wise sales analysis
* Customer analysis
* Category-wise performance
* Monthly/Quarterly sales trends
* Top-performing products
* Easy-to-understand visualizations

## 🔍 Key Analysis

The dashboard can be used to answer questions such as:

1. What is the total sales?
2. Which region generates the highest sales?
3. Which product is the top-selling product?
4. Which category performs best?
5. Which customers contribute the most sales?
6. How do sales change over time?
7. Which region has the highest quantity sold?
8. What are the most profitable products?
